Chatbot ODD - URCA

Bienvenue sur le projet Chatbot ODD !
Ce chatbot intelligent qui répond à toutes vos questions sur les Objectifs de Développement Durable (ODD) en français et en anglais.

Fonctionnalités principales :
  • Recherche intelligente et réponses contextuelles sur les ODD
  • Interface accessible et bilingue
  • Utilisation de modèles IA avancés (Haystack, Sentence Transformers)
  • Exploration de données enrichies (JSON, Excel)
Voir le code sur GitHub

Tester l'application

Pour lancer le chatbot en local :

  1. Clonez le dépôt GitHub
  2. Installez les dépendances Python (pip install -r requirements.txt)
  3. Lancez l'application avec streamlit run main.py

À propos

Chatbot ODD est un projet open source développé par Ismael Madou.
Il vise à sensibiliser et à informer sur les Objectifs de Développement Durable (ODD) grâce à l'intelligence artificielle.

Le code source est disponible sur GitHub.
Pour plus d'informations techniques, consultez la documentation.

Ce projet s'appuie sur des technologies modernes (Streamlit, Haystack, Sentence Transformers) et des données enrichies (JSON, Excel).
